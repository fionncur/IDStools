 vieweccomposition
###################

*vieweccomposition* shows EC composition (ECRH and ECCD profiles)

**************************
 Syntax vieweccomposition
**************************

   .. command-output:: vieweccomposition -h

***************************
 Example vieweccomposition
***************************

   .. code-block:: bash

        $ vieweccomposition --uri "imas:mdsplus?user=public;pulse=134173;run=2326;database=TEST;version=3"
