viewhcdwaves
============

*viewhcdwaves* shows hcd waveforms

Syntax viewhcdwaves
~~~~~~~~~~~~~~~~~~~

   .. command-output:: viewhcdwaves -h

Example viewhcdwaves
~~~~~~~~~~~~~~~~~~~~

    .. code-block:: bash

        $ viewhcdwaves --uri "imas:mdsplus?user=public;pulse=134173;run=101;database=TEST;version=3"
