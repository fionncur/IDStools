plothcdplots
============

*plothcdplots* shows plots from distributions and waves for different data entries for analysis

Syntax plothcdplots
~~~~~~~~~~~~~~~~~~~

   .. command-output:: plothcdplots -h

Example plothcdplots
~~~~~~~~~~~~~~~~~~~~

    .. code-block:: bash

        $ plothcdplots -ech 134173/101/public/MDSPLUS/TEST/3 -nbi 130012/115/public/MDSPLUS/TEST/3 -fus 130012/115/public/MDSPLUS/TEST/3 -icrh 130012/15/public/MDSPLUS/TEST/3
