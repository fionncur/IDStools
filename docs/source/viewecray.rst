###########
 viewecray
###########

*viewecray* shows plots for RF Waves and depositions. This script uses
output of TORBEAM code.
`refer data dictionary <https://sharepoint.iter.org/departments/POP/CM/IMDesign/Data%20Model/sphinx/latest.html>`_.

******************
 Syntax viewecray
******************

   .. command-output:: viewecray -h

*******************
 Example viewecray
*******************

   .. code-block:: bash

        $ viewecray --uri "imas:mdsplus?user=public;pulse=134173;run=2326;database=TEST;version=3" -mdesc wall
