
# IMAS IDS Python Tools

## Description

This is the package which provides different tools to interact with IDS database. It also helps physists to quickly execute some task without reinventing the wheel.

## Using IDS Tools

These tools are installed on sdcc at ITER and available as shell commands

Also can be installed separately using pip install
```Shell
git clone ssh://git@git.iter.org/imas/idstools.git
cd idstools
pip install . [--user]
```
